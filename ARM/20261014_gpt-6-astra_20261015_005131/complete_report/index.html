7. Risk framework and data limitations¶

For any ARM setup, position sizing should follow the actual structural stop:

Position size ≤ predetermined dollar risk ÷ absolute entry-to-stop distance

ATR is useful for checking whether that stop is unrealistically tight, but it should not replace a structural invalidation level. Gaps, slippage, and execution costs can increase losses beyond the planned amount.
