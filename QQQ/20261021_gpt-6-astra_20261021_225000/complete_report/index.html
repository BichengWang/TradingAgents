9. Risk framework for the decision-maker¶

For any contemplated QQQ position:

  • Match the timeframe: A daily trade should not inherit the much wider weekly trailing level without a corresponding reduction in position size.
  • Define invalidation first: Choose the condition that disproves the setup before selecting position size.
  • Account for volatility: Compare the proposed stop distance with the current ATR.
  • Check reward against risk: The distance to the first realistic exit reference should compensate for the stop required.
  • Allow for gaps and slippage: A stop order does not guarantee execution at the trigger price.

A basic sizing relationship is:

Position size = permitted monetary risk ÷ estimated per-share loss at the stop, including execution allowance.
