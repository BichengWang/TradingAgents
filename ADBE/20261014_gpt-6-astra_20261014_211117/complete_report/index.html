Risk implementation¶

A useful sizing framework is:

Position size = predefined cash-risk budget ÷ distance from actual entry to protective stop

Use a price-based invalidation point, then check that the stop distance is sensible relative to ATR. If the necessary stop is wide, reduce position size rather than forcing a tighter stop.

For perspective, the weekly SuperTrend line is 34.60 below the latest close, substantially wider than a normal tactical daily stop. A weekly-position framework and a short-term swing framework should therefore not be mixed casually.
