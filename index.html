Regeneration Skill¶

When ticker folders are upgraded with newer report data, regenerate this homepage instead of editing the table by hand:

  1. Add each completed run under docs/<TICKER>/<YYYYMMDD>_<MODEL>_<YYYYMMDD>_<HHMMSS>/ with complete_report.md, 3_trading/trader.md, and 5_portfolio/decision.md present.
  2. Run python scripts/report_workflow.py --analysis-date YYYYMMDD from the repository root.
  3. Review docs/index.md and the affected docs/<TICKER>/index.md files in git diff.
  4. If a row has a missing value, check that the new report includes **Rating**, **Current Price**, **Price Target**, **Time Horizon**, and **Action**.

The generator groups summaries by analysis date and chooses the newest run per ticker/model pair by run-start timestamp within each date.
