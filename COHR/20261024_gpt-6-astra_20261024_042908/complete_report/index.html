8. Volatility and implementation risk¶

The latest verified ATR is 21.11, approximately 10.1% of the latest closing price, calculated as ATR divided by close.

That is substantial relative volatility. ATR measures average true range; it is not a guaranteed daily move or a statistical confidence interval.

A useful illustration is the distance between the latest close and session low:

  • Close: 209.29
  • Session low: 203.55
  • Difference: 5.74, approximately 0.27 ATR

A stop placed only slightly beneath that low could be vulnerable to ordinary price noise. Widening a stop without reducing position size, however, increases account risk.

The basic sizing relationship is:

Position size = permitted dollar loss ÷ planned entry-to-stop distance

The stop distance should reflect actual trade structure, current volatility, and execution costs. Gaps and slippage can cause realized losses to exceed the planned amount.
