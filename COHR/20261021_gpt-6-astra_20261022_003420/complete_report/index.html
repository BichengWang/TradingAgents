For scale:

  • 1 ATR: 20.95 per share.
  • 1.5 ATR: approximately 31.43 per share.
  • 2 ATR: 41.90 per share.

These are illustrative distances, not recommended stop levels.

Conversely, the daily bearish SuperTrend line is 54.62 above the close, creating a materially larger risk distance if used as a short-position invalidation reference.

A practical sizing framework is:

Position size = chosen dollar-risk budget ÷ absolute distance between entry and stop

The stop should correspond to the setup’s invalidation point and allow for volatility. Position size should then adapt to that distance—not the other way around. Gaps and slippage can produce losses beyond the planned amount.
