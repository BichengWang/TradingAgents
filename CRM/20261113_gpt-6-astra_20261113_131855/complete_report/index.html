Position size = maximum acceptable dollar risk ÷ entry-to-stop distance

Allow for slippage, fees, and overnight gaps. A weekly-trend position and a tactical bounce position require different invalidation rules; using a wide weekly reference for a short-lived bounce can create an unfavorable risk budget.
